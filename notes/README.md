# pyquiz\notes Folder

This folder stores PDFs accessible in pyquiz flashcards as [p]. Can be opened during quizzes by pressing:  p  in quiz mode.

Cards in `quiz_cards.json` may reference files here using relative paths.

## 📇 Index

- bayes_notes.py  Contains my notes on Bayes Theorem to go with flashcards. Written to be useful for ML and data analysis work using numpy.
